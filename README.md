# Marc Cedric Asas Portfolio

A Vercel-ready portfolio template for Marc Cedric Asas, designed around a quiet editorial resume layout inspired by the provided references.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Phosphor Icons
- Vercel deployment defaults

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy To Vercel

Import the GitHub repository in Vercel. The default build settings work:

- Framework preset: Next.js
- Build command: `npm run build`
- Output directory: `.next`

## Customize

Edit portfolio content in [lib/portfolio-data.ts](./lib/portfolio-data.ts). Replace gallery image URLs, social links, and project details as the portfolio grows.
